Lean code harness // local-first // approval-gated

Keep the brain.
Lose the bulk.

SkinnyCoder is a deliberately small TypeScript CLI that delegates reasoning to your installed Codex CLI while keeping file access, diffs, approvals, undo, and retained context visible and local.

01

One action at a time

[01]Ask

Give SkinnyCoder a focused task. Multiline pastes stay together as one request.

[02]Delegate

Codex returns one compact JSON action and durable skill state instead of a large agent framework.

[03]Inspect

Reads are paged with continuation commands. Diffs appear before writes. Scope keeps files bounded.

[04]Approve

You authorize one complete diff; related file edits apply atomically and undo together.

02

Command deck

Control

/help
Show the complete command reference.
/status
Show cwd, model, reasoning, scope, and changes.
/model [name]
Inspect or override the model for this session.
/reasoning [level]
Choose low through ultra; reset with default.
/login
Run Codex login when authentication is needed.

Focus

/scope [paths]
Enforce narrow file boundaries without preloading files.
/files [path]
List up to 80 entries inside the active scope.
/read <file> [--from N]
Display up to 400 lines with an exact continuation command.
/context
Inspect retained context and recent token usage.
/clear
Discard retained conversation turns.

Build

/edit <file> ...
Preserve explicit edit intent, create missing targets, then review the diff.
/run <command>
Approve a direct command and see its exit code, stdout, and stderr.
/review
Review scoped uncommitted changes without retaining the diff.
/diff
Show Git changes within the active scope.
/changes
List files changed by SkinnyCoder.
/undo
Reverse the last single edit or atomic multi-file patch.

Guided skills

/skills
Check trusted BrainIT workflow installation and active status.
/continue
Resume an active skill from its durable checkpoint.
/start-an-app [idea]
Interview, agree a build sheet, then scaffold in a new folder.
/security-scanner
Run an OWASP Top 10:2025 audit of the current project.
/skills stop
Leave the active workflow without uninstalling it.

Research + exit

/web <query>
Run an isolated, cited web search through Codex.
/model default
Return to Codex model configuration.
/reasoning default
Return to configured reasoning effort.
/scope clear
Restore the full working directory boundary.
/exit
Close the session.
03

Launch small

# FROM ANY TERMINAL
skinnycoder

skinnycoder --cwd H:\path\to\project
skinnycoder --model gpt-5.6-terra
skinnycoder --reasoning medium
skinnycoder --version

What stays skinny

/run output never enters model context. /web uses an ephemeral search and retains neither the query nor answer.

/scope stores only path names. SkinnyCoder sends at most four recent turns; active skills add capped state plus a content-free local action checkpoint and resume without repeating confirmed approvals.

Trusted skills install only on first use and only after approval. Their workflows keep the same scope, diff, command, and write gates.

Related edits may arrive as one bounded patch_files diff. It rejects links and junctions, validates before writing, rolls back partial failures, and never includes shell commands.

Shell commands are not constrained by file scope. Every command is previewed and requires your approval.

04

Install and release

# RECOMMENDED: NPM GLOBAL INSTALL
npm install -g skinnycoder
skinnycoder --version

This installs npm's current latest release. It does not clone or link a GitHub working tree.

# CURRENT GITHUB SOURCE
git clone https://github.com/brainit-consulting/skinnycoder.git
cd skinnycoder
npm ci
npm run build
npm link

The source route is for contributors and current GitHub code; rebuild after source changes.

Tokenless npm publishing

Maintainers release from an intentional vX.Y.Z tag. A no-OIDC job verifies the tag, main-branch ancestry, build, tests, and package contents. A separate minimal job receives a short-lived npm identity and publishes the verified tarball with lifecycle scripts disabled.

No long-lived npm token is stored in GitHub.

skinnycoder@0.2.2 is published and must not be published again. The npm owner must verify the brainit-consulting/skinnycoder binding to publish-npm.yml in npm's Trusted publishing settings with npm publish permission.
