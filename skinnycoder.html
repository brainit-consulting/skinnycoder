Lean code harness // local-first // approval-gated

Keep the brain.
Lose the bulk.

SkinnyCoder is a deliberately small TypeScript CLI that delegates reasoning to your installed Codex CLI while keeping file access, diffs, approvals, undo, and retained context visible and local.

01

One action at a time

[01]Ask

Give SkinnyCoder a focused coding task in plain language.

[02]Delegate

Codex returns one compact JSON action instead of a large agent framework.

[03]Inspect

Reads are capped. Diffs appear before writes. Scope keeps files bounded.

[04]Approve

You authorize edits and commands; SkinnyCoder tracks changes for undo.

02

Command deck

Control

/help
Show the complete command reference.
/status
Show cwd, model, reasoning, scope, and changes.
/model [name]
Inspect or override the model for this session.
/reasoning [level]
Choose low through ultra; reset with default.
/login
Run Codex login when authentication is needed.

Focus

/scope [paths]
Enforce narrow file boundaries without preloading files.
/files [path]
List up to 80 entries inside the active scope.
/read <file>
Display a capped local file preview.
/context
Inspect retained context and recent token usage.
/clear
Discard retained conversation turns.

Build

/edit <file> ...
Ask Codex for a focused edit, then review its diff.
/run <command>
Approve a direct local command without a model call.
/review
Review scoped uncommitted changes without retaining the diff.
/diff
Show Git changes within the active scope.
/changes
List files changed by SkinnyCoder.
/undo
Reverse the last SkinnyCoder file change.

Guided skills

/skills
Check trusted BrainIT workflow installation and active status.
/start-an-app [idea]
Interview, agree a build sheet, then scaffold in a new folder.
/security-scanner
Run an OWASP Top 10:2025 audit of the current project.
/skills stop
Leave the active workflow without uninstalling it.

Research + exit

/web <query>
Run an isolated, cited web search through Codex.
/model default
Return to Codex model configuration.
/reasoning default
Return to configured reasoning effort.
/scope clear
Restore the full working directory boundary.
/exit
Close the session.
03

Launch small

# FROM ANY TERMINAL
skinnycoder

skinnycoder --cwd H:\path\to\project
skinnycoder --model gpt-5.6-terra
skinnycoder --reasoning medium
skinnycoder --version

What stays skinny

/run output never enters model context. /web uses an ephemeral search and retains neither the query nor answer.

/scope stores only path names. SkinnyCoder sends at most four recent turns; active skills add only a capped workflow summary.

Trusted skills install only on first use and only after approval. Their workflows keep the same scope, diff, command, and write gates.

Shell commands are not constrained by file scope. Every command is previewed and requires your approval.
